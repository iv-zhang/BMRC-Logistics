# BMRC UI and UX

Use [the bmrc-ui skill](../skills/bmrc-ui/SKILL.md) and [the shared standards](../../docs/ui-ux-standards.md).

This command is a compatibility entrypoint. The shared document replaces the former duplicated layout snippets and conflicting checklist. Read it before changing UI, copy, forms, navigation, or feature flows. Codex and Claude Code use the same standard.

For an audit, list evidence-backed issues before proposing fixes. For implementation, preserve existing domain decisions and repository authorization/verification rules. The current backlog is [the UI/UX audit plan](../../docs/plans/2026-10-22-ui-ux-audit-and-plan.md).
